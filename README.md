## Sobre o projeto
A primeira versão (MVP 1) do trabalho prático estabelece a base do servidor HTTP/1.1 em linguagem C com Pthreads, implementando **concorrência multithreaded**, **suporte a conexões persistentes**, **transferência de arquivos estáticos por blocos** e **tratamento de códigos de status HTTP**.
A segunda versão (MVP 2) do trabalho prático evolui o servidor HTTP/1.1 multithreaded com conexões persistentes, incorporando mecanismos de **Qualidade de Serviço (QoS)**, **Controle de Admissão**, **Estimativa de RTT** e **Monitoramento em Tempo Real**.
> O projeto foi desenvolvido e testado em ambiente Linux/WSL Ubuntu.

## Requisitos
Para compilar e executar o projeto, é necessário um ambiente Linux com suporte à linguagem C e à biblioteca POSIX Threads.
