## Sobre o projeto
Servidor HTTP/1.1 desenvolvido em Linguagem C com Pthreads, capaz de atender múltiplos clientes simultaneamente com conexões persistentes (keep-alive). A versão final incluirá mecanismos de Qualidade de Serviço (QoS), controle de admissão e estimativa de RTT e largura de banda.
O projeto foi desenvolvido e testado em ambiente Linux/WSL Ubuntu.

## Requisitos
Para compilar e executar o projeto, é necessário um ambiente Linux com suporte à linguagem C e à biblioteca POSIX Threads.
